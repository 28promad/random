# Phillip Madadangoma - Personal Portfolio

A modern, responsive personal portfolio website built to showcase my software development projects and professional profile.

## Features

- **Dynamic GitHub Projects**: Automatically fetches and displays recent public repositories from my GitHub account using the GitHub REST API.
- **Modern UI/UX**: Clean, minimalist aesthetic with fluid background animations and interactive elements.
- **Responsive Design**: Fully responsive layout that adapting to desktop, tablet, and mobile devices seamlessly.
- **Custom Scrollbar**: Features a unique winding snake SVG scrollbar tracker.

## Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Vanilla CSS for styling, custom properties, animations, and responsive layouts.
- **JavaScript**: Vanilla JS for DOM manipulation, fetching GitHub API data, and handling the interactive project carousel.
- **FontAwesome**: For scalable vector icons.
- **Google Fonts**: Utilizing Inter and Outfit typography.

## Getting Started

To view the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/28promad/random.git
   ```

2. Open the `index.html` file in your preferred web browser. No local development server is required as it uses purely vanilla frontend technologies.
